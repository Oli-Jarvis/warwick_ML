# Earlier implementations

These files are retained as reference copies and are not imported by the active
three-step workflow. The earlier installer/bridge is incompatible with the
current subprocess integration. Do not run it to set up the current workflow.

The active conformer functions were extracted unchanged from `legacy_dim.py`
into `../conformers.py`. Historical analysis and reference-building details are
documented in `../REFERENCE_SETUP.md`.
