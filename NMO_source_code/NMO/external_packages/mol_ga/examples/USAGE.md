# mol_ga + NMO — Usage Guide

## Running the GA

```bash
python maximize_nmo_oracle.py \
    --config <nmo_config.ini> \
    --mode <smiles|ggs|ggs_native> \
    --offspring_size 100 \
    --start_population_size 100
```

The NMO config file defines the oracle objective, budget, and all physics parameters.
`--mode` controls only the mol_ga side: how molecules are represented and how offspring are generated.

---

## Modes

### `--mode smiles` (default)

Standard SMILES-based GA.  Starting population is drawn from ZINC250k.
Offspring are generated by mol_ga's built-in graph-GA operators (atom/bond mutations and crossover on molecular graphs).

```bash
python maximize_nmo_oracle.py --config my_config.ini --mode smiles
```

### `--mode ggs`

Population stored as Group-SELFIES (GGS) encoding strings.
Offspring operators work at the token level:

| Operator | Description |
|---|---|
| `mutate_ggs` | Swaps one group token for another with the same number of attachment points |
| `crossover_ggs` | Splices a prefix of parent A with a suffix of parent B at unit-boundary positions |

Requires `grammar_path` in the `[General]` section of the NMO config.

```bash
python maximize_nmo_oracle.py --config my_config.ini --mode ggs
```

### `--mode ggs_native`

Same GGS population, but offspring are generated by the graph-level operators
implemented inside the `GGS` class.  These parse the molecular graph before mutating,
so they never produce structurally broken encodings.

**Mutations** (one is chosen at random per molecule, all tried on failure):

| Operator | Description |
|---|---|
| `group_mutation` | Replaces a node with another group that has enough attachment points |
| `bond_mutation` | Changes the attachment-point index of one bond |
| `anchor_pos_mutation` | Moves the electrode anchor to a different free AP on the same group |
| `anchor_group_mutation` | Reassigns the anchor to a neighbouring leaf node |
| `insert_group_mutation` | Inserts a new group in the middle of a branch |
| `insert_start_end_group_mutation` | Inserts a new group at the start or end |
| `truncate_mutation` | Removes a group and re-wires the graph |
| `insert_branch_mutation` | Attaches a new branch to any node with a free attachment point |

**Crossover:** `single_point_crossover` — cuts both parent graphs at a random edge and swaps sub-graphs, producing **two** children per pair.

Requires `grammar_path` in the `[General]` section of the NMO config.

```bash
python maximize_nmo_oracle.py --config my_config.ini --mode ggs_native
```

## Choosing a mode

| | `smiles` | `ggs` | `ggs_native` |
|---|---|---|---|
| Population | SMILES | GGS strings | GGS strings |
| Operators | graph-GA (built-in) | token-level | graph-level |
| Grammar needed | No | Yes | Yes |
| Anchor positions | Implicit (auto-attached) | Implicit | Explicit (grammar-defined) |
| Best for | TDC benchmarks, fast tests | GGS prototyping | Transport oracles (ZT, phonon, upconversion) |
